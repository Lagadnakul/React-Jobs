# Contributing to React Jobs

Thank you for your interest in contributing to React Jobs! We appreciate all contributions, whether they're bug reports, feature requests, documentation improvements, or code changes.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct. Please be respectful and considerate of others.

## How to Contribute

### Reporting Bugs

If you find a bug in the project, please create an issue with the following information:

1. A clear, descriptive title
2. A detailed description of the issue
3. Steps to reproduce the bug
4. Expected behavior
5. Actual behavior
6. Screenshots (if applicable)
7. Environment information (OS, browser, etc.)

### Suggesting Features

We welcome feature suggestions! To suggest a feature:

1. Create an issue with a clear, descriptive title
2. Provide a detailed description of the proposed feature
3. Explain why this feature would be useful to the project
4. Include any relevant mockups or examples

### Pull Requests

We actively welcome your pull requests!

1. Fork the repo and create your branch from `main`
2. Install dependencies: `npm install`
3. If you've added code that should be tested, add tests
4. Ensure all tests pass: `npm test`
5. Make sure your code lints: `npm run lint`
6. Update the documentation if necessary
7. Create a pull request!

### Development Workflow

1. Clone the repository
   ```bash
   git clone https://github.com/yourusername/React-Jobs.git
   cd React-Jobs
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the development server
   ```bash
   npm run dev
   ```

4. Start the JSON server for API
   ```bash
   npm run server
   ```

### Coding Style

Please follow the existing coding style in the project. We use ESLint to enforce coding standards.
